## Background

TASK-0001 analysis identified a pre-existing C1128 failure in `src/map/skill.cpp` under MSVC x64-Debug.
The fix (adding `/bigobj`) was briefly present in the codebase via an unauthorized Codex change; it was
reverted in commit `77cb9f523` because it was made outside task scope. This task formally tracks the
approved implementation.

## Acceptance Criteria

- [ ] `src/map/CMakeLists.txt` includes `target_compile_options(map-server PRIVATE /bigobj)` inside `if(MSVC)`.
- [ ] Build of `map-server` with MSVC x64-Debug completes without C1128.
- [ ] Build result documented in execution log.

## Implementation Notes

- Constraints: Change must be MSVC-only (`if( MSVC )` guard) so other toolchains are unaffected.
- Dependencies: Requires CMake re-configure after editing CMakeLists.txt.
- Risks: Low. `/bigobj` is a well-known MSVC flag for large translation units; no semantic change to output binary.
